# Asset Maintenance Tracker

A backend system built with **Spring Boot**, **PostgreSQL**, and **Java 17** that tracks assets and predicts maintenance needs. Aligns with Enterprise Asset Management (EAM) principles like IFS.

## Features

- CRUD operations for Assets
- Track Maintenance Logs (Corrective & Preventive)
- RESTful API endpoints
- PostgreSQL database integration
- Spring Security configured (can be enabled or disabled)
- Enterprise-level layered architecture

## Technologies

- Java 17
- Spring Boot 3.x
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok
